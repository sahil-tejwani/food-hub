# FOODHUB - Food Ordering System

A simple Java Swing desktop application for ordering food items.

## About

FOODHUB is a GUI-based food ordering system built in Java. It supports user signup/login, browsing a food menu, placing orders, and an admin panel for managing food items.

## Features

- User Signup & Login
- View Food Menu
- Search Food by Name
- Place Orders
- View Order History
- Cancel Orders
- Admin Panel (Add Food Items)

## How to Run

1. Make sure you have **Java JDK** installed.
2. Compile the file:
   ```
   javac FOODHUB.java
   ```
3. Run the application:
   ```
   java FOODHUB
   ```
